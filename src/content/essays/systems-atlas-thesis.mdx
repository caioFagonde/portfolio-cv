The central thread is systems engineering: understand the boundaries, interfaces, assumptions, and feedback loops of a problem before optimizing a component.

Aerospace makes this unavoidable. An orbit propagator is not only an integrator. A remote-sensing product is not only a raster. A computer-vision system is not only a model. A useful agent is not only a language model.

This atlas is organized around those interfaces.
