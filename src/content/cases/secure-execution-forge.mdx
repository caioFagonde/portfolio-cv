## Problem

A scientific or agentic platform eventually needs to run code: simulations, preprocessing, extraction scripts, tests, notebooks, and model jobs. That execution must be bounded.

## Direction

The Forge concept separates job specification, sandbox profile, resource budget, filesystem policy, network policy, and audit trace.

## Status

This is a research and architecture direction, not a shipped product claim.
