## Problem

Change detection is not one algorithm. Deforestation, degradation, encroachment, flooding, burn scars, crop stress, and construction all require different temporal, spectral, spatial, and operational assumptions.

## System direction

The practical design is a portfolio of methods wrapped by artifact contracts: input scenes, masks, confidence maps, method agreement maps, polygon statistics, and reports.

## Design rule

The output should not only say “change.” It should show what changed, where, according to which method, with what confidence, and how the result aggregates across spatial hierarchy.
