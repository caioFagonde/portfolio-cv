## Problem

Specialist agents need access to user data and application modules, but unrestricted tool use is not acceptable in professional software.

## Architecture

The architecture uses typed tools, permission checks, read-only defaults, query guards, source citations, audit traces, and explicit uncertainty about missing evidence.

## Tool access

The service checks permissions and query limits before executing a tool. Answers include references to the documents or records used.
