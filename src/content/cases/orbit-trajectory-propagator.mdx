## Problem

Orbit analysis requires numerical rigor and systems thinking: initial state uncertainty, perturbations, integration stability, reference frames, and mission objectives must be handled together.

## Architecture

A clean propagator separates state representation, force models, integrators, event detection, and report generation. The same design discipline applies to future software libraries: keep physics, numerics, and artifacts separate.

## Technical themes

- adaptive numerical integration;
- orbital perturbation modeling;
- state-space reasoning;
- control and maneuver planning;
- reproducible simulation outputs.
