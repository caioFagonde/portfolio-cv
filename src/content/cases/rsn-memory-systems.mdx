## Problem

Agentic systems need memory, but memory without structure becomes a liability: irrelevant retrievals, stale facts, incoherent tool use, and no provenance.

## Direction

The branch studies memory as a typed, evaluated, clustered system rather than a single vector store.

## Integration

This belongs inside agent-foundry when it improves retrieval quality, workflow validity, or specialist-agent reliability.
